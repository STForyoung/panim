# Panim

A mobile app for an atmosphere of meditating on scripture. 
Involves Create personal snippets of Bible passages and your reflections, and receiving them as notifications 
on defined times during the day.

## Stack
- Expo (React Native) + TypeScript
- Expo Router (file-based navigation)
- expo-sqlite (local storage)
- expo-notifications (scheduled push notifications)

## Getting Started
```bash
npm install
npx expo start
```
